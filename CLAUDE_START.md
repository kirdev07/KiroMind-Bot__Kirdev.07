# Первый запрос для Claude Code / Codex

Ты работаешь с НОВЫМ Android-проектом **KiroMind Bot 1.0**. Прочитай `AGENTS.md`, `README_RU.md`, `DESIGN_SPEC.md`, `ARCHITECTURE.md` и `ROADMAP.md` перед изменениями.

## Задача на первом этапе

1. Открой именно этот проект, **не** старый Kiro Bot/KiroMind 4.0 и не репозиторий-источник.
2. Настрой локальный официальный Gradle Wrapper 9.4.1, проверь SDK 37 и Gradle Sync.
3. Собери `:app:assembleDebug` и запусти `:app:testDebugUnitTest`.
4. Исправь обнаруженные ошибки, не меняя одобренный UI без необходимости.
5. Проверь настоящую навигацию пяти вкладок, все семь настроек, экран редактора и тестовый чат.
6. Проверь на устройстве Android 10+ и адаптацию для компактных экранов, системного шрифта и TalkBack.
7. Составь `BUILD_REPORT.md`: что собрано, что проверено, какие ошибки исправлены и что пока демонстрационное.

## Архитектурные правила

- База ответов: `feature/answers/{domain,data,ui}`. Реальную Room базу вводить отдельным следующим этапом с тестами.
- Движок: `feature/engine/domain/MindCore.kt`, **не** `Brain`, **не** перенос кода из старого бота.
- Экран: `feature/*/ui`, никаких Android UI импортов в `feature/engine/domain`.
- Telegram: `feature/telegram/api/`, пока интерфейс без реального подключения.
- Секреты: `feature/security/`, не вводить plaintext fallback.
- Новое приложение, версия 1.0, applicationId `com.kirdev.kiromindbot`.
- Пять нижних вкладок: Главная / Терминал / База / ИИ / Настройки.
- Ничего не публикуй и не отправляй в GitHub без явной команды.

**Сначала собери и проверь UI Alpha 1, затем остановись и покажи отчёт.** Не реализуй Telegram API, внешние модели и импорт старой базы на этом шаге.
