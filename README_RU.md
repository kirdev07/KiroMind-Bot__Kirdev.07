# KiroMind Bot 1.0 — инструкция

Создан самостоятельный Android-проект **KiroMind Bot**, версия **1.0**, новый движок **MindCore**.
Старый проект Kiro Bot 3.0 остался нетронутым. У приложения собственный package `com.kirdev.kiromindbot`.

## Структура

- `feature/answers/domain/` — новые модели вопросов, ответов и вложений.
- `feature/answers/data/` — интерфейс хранилища ответов и отдельная временная демо-реализация.
- `feature/answers/ui/` — экран базы и полноэкранный редактор.
- `feature/engine/domain/` — **MindCore**, независимый алгоритм, тестируемый без Android.
- `feature/engine/ui/` — экран управления движком, тестовый чат и провайдеры.
- `feature/home/ui/` — главная.
- `feature/terminal/` — журнал и экран терминала.
- `feature/settings/` — отдельные страницы настроек.
- `feature/telegram/api/` — интерфейс Telegram, **пока без подключения**.
- `feature/security/` — интерфейс защищённого хранилища секретов.
- `core/navigation/` — пять вкладок и отдельные маршруты.
- `core/designsystem/` — единая чёрно-белая тема.

## Запуск

1. Распакуй ZIP и открой папку `KiroMind-Bot-1.0` через Android Studio.
2. Установи JDK 17, Android SDK 37 и совместимую Android Studio.
3. Проект использует AGP 9.2.0 / Gradle 9.4.1 / Compose BOM 2026.08.00.
4. При первом запуске Gradle может потребоваться восстановить официальный Wrapper JAR, его нет в архиве. Для этого с доверенной установленной Gradle 9.4.1 выполни `gradle wrapper --gradle-version 9.4.1`, затем Gradle Sync.
5. Собери `app` и проверь на эмуляторе/телефоне Android 10+.

### Сейчас работает

Пять вкладок, демонстрационная кнопка запуска, терминал, база и редактор с типами вложений, поиск по базе, избранное, точный поиск MindCore в тестовом чате, настройки.

### Пока не работает

Подключение Telegram, передача реальных медиа, постоянная база, запуск фонового сервиса, внешние ИИ, настройка настоящих API-ключей, реальная защита от спама.

**Внимание:** на этом компьютере нет Android SDK и Gradle, поэтому успешная сборка APK ещё не подтверждена. Проверку компиляции интерфейса проводим в Android Studio.
